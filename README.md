# Amazon-Mock 🛒  
A mock version of Amazon's online shopping platform, built with HTML, CSS, JavaScript, and backend integration to simulate e-commerce functionalities.

## Features ✨  
- 🛍️ **Interactive Shopping Cart** – Users can add/remove items and adjust quantities dynamically.  
- 🔄 **Order Tracking System** – Displays order history and tracking status.  
- 💳 **Checkout Page** – Simulates a purchase process with order summary.  
- 📦 **Backend Data Handling** – Uses mock data for products and order management.  

## Project Structure 📂  
```
Amazon-Mock/
│── backend/      # Backend logic (e.g., APIs, database integration)
│── data/         # Mock product/order data
│── images/       # Assets like product images and icons
│── scripts/      # JavaScript files for interactivity
│── styles/       # CSS files for styling
│── amazon.html   # Main homepage (Product Listings)
│── checkout.html # Checkout page
│── orders.html   # Order history page
│── tracking.html # Order tracking page
│── README.md     # Project documentation
```

## Technologies Used 🛠️  
- **Frontend:** HTML, CSS, JavaScript  
- **Styling:** Custom CSS, Responsive Design  
- **Backend:** Mock data handling  

## How to Run 🚀  
1. Clone the repository:  
   ```bash
   git clone https://github.com/celineWang14/Amazon-Mock.git
   ```
2. Navigate to the project folder:  
   ```bash
   cd Amazon-Mock
   ```
3. Open `amazon.html` in a browser.
